# Загальний план тестування

## 1. Основні цілі
- Переконатися у коректній роботі валідації даних
- Забезпечити зручний досвід для користувача
- Запобігти збереженню некоректних даних

## 2. Основні напрямки тестування

### 2.1. Клієнтська частина
- Перевірка обов'язкових полів
- Валідація форматів даних
- Відображення помилок

### 2.2. Серверна частина
- Перевірка даних перед збереженням
- Обробка помилок
- Захист від невалідних запитів

## 3. Критерії успіху
- Всі обов'язкові поля перевіряються
- Користувач отримує зрозумілі повідомлення
- Система не приймає невалідні дані

## 4. Графік
- Планування -> 2 дні
- Виконання -> 3-7 днів
- Аналіз результатів -> 2 дні
