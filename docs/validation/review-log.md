## Наша Рефлексія

### Внесені Зміни

1. **Зміна:** Виправлено баг з редагуванням профілю

   **Чому:** ProfileBloc створювався без ініціалізації стану, використовувався антипатерн з вкладеним BlocProvider, і виникала помилка type cast при роботі з Firestore timestamp.

   **Виправлення:**
   - ProfileBloc тепер ініціалізується з завантаженням профілю в `main_navigation.dart`
   - Видалено вкладений BlocProvider у `profile_page.dart`
   - Замінено Firestore transaction на update + read у `profile_remote_data_source.dart`
   - Додано безпечну обробку типів для поля `createdAt` у `user_model.dart`

2. **Зміна:** Виправлено overflow у recovery status статистиці

   **Чому:** Row з статистиками не поміщався на екрані при відображенні всіх 4 елементів, викликаючи overflow на 35 пікселів.

   **Виправлення:**
   - Обгорнуто Row у SingleChildScrollView з горизонтальним скролом у `recovery_status_card.dart`
   - Видалено невикористані імпорти та поля

3. **Зміна:** Додано видалення старих аватарок при завантаженні нових

   **Чому:** При зміні аватарки старі файли залишалися у Firebase Storage, накопичуючи непотрібні дані.

   **Виправлення:**
   - Додано логіку видалення старої аватарки перед завантаженням нової у `profile_remote_data_source.dart`
