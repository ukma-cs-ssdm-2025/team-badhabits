## Короткий зміст
**Wellity** - це крос-платформний мобільний застосунок, який допомагає користувачам відстежувати фізичну активність, формувати корисні звички та аналізувати свій прогрес.

Додаток поєднує відстеження звичок, керування тренуваннями та забезпечення соціальної взаємодії та обміну досягненнями між користувачами, підтримуючи мотивацію та заохочуючи регулярне виконання завдань.

## Досягнення проекту

### 1. Реалізовано основний функціонал
- **Аутентифікація та профілі**
  - Безпечна система реєстрації та входу
  - Керування профілем користувача
  - Ролі користувачів (звичайні користувачі та тренери)

- **Відстеження звичок**
  - Створення власних звичок з різними типами полів
  - Щоденне відстеження прогресу
  - Шаблони для поширених звичок

- **Керування тренуваннями**
  - Бібліотека вправ з детальними інструкціями
  - Створення та налаштування тренувань
  - Відстеження тренувань у реальному часі з таймерами

- **Нотатки та щоденник**
  - Вільні текстові нотатки
  - Контекстні нотатки до звичок та тренувань

### 2. Технічна реалізація
- **Клієнтська частина:** Flutter (iOS та Android)
- **Серверна частина:** Node.js з Express
- **База даних:** PostgreSQL
- **Розгортання:** Railway.app (Європа, Захід)
- **CI/CD:** GitHub Actions

### 3. Тестування та якість
- **Тестування бекенду**
  - 70/70 тестів успішно пройдено
  - Покриття коду: 93.56%
  - Модульні та інтеграційні тести

- **Тестування фронтенду**
  - Віджет-тести для компонентів інтерфейсу
  - Інтеграційні тести для основних сценаріїв використання

## Ключові показники
- **Доступність API:** 99.9% (моніторинг через Railway)
- **Покриття тестами:** 93.56% (бекенд)
- **Метрики DORA:**
  - Частота розгортань: 2 рази на тиждень
  - Час виконання змін: 1 хвилина
  - Частота невдалих змін: 33%
  - Час відновлення: 3 тижні
